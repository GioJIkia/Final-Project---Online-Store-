ეს არის სრულფასოვანი ელექტრონული კომერციის (E-Commerce) ვებსაიტი, რომელიც შექმნილია Django ფრეიმვორკის გამოყენებით. აპლიკაცია მომხმარებლებს საშუალებას აძლევს დაათვალიერონ პროდუქცია, გამოიყენონ მრავალმხრივი ფილტრები, მართონ საკუთარი კალათა და დატოვონ შეფასებები/რეიტინგები.

ძირითადი ფუნქციონალი:

ადმინ პანელი (Django Admin):

1. პროდუქტების, კატეგორიებისა და ბრენდების მართვა (დამატება, რედაქტირება, წაშლა).
2. მომხმარებლების შეკვეთებისა და კალათების მონიტორინგი.
3. მომხმარებელთა შეფასებებისა და რეიტინგების ადმინისტრირება.

ავტორიზაციის სისტემა:

1. მომხმარებლების რეგისტრაცია.
2. სისტემაში შესვლა.
3. გასვლა.

პროდუქციის კატალოგი და ფილტრაცია:

1. ძებნა პროდუქტის დასახელების მიხედვით.
2. ფილტრაცია კატეგორიის, ბრენდის, მაქსიმალური ფასისა და მინიმალური რეიტინგის მიხედვით.
3. პროდუქციის სორტირება ფასის ზრდადობისა და კლებადობის მიხედვით.

ინტერაქტიული კალათა:

1. პროდუქტის კალათაში დამატება როგორც კატალოგიდან, ასევე დეტალური გვერდიდან.
2. რაოდენობის მართვა (მომატება/დაკლება) და ნივთის წაშლა კალათიდან.
3. კალათაში არსებული ნივთების ჯამური ღირებულებისა და რაოდენობის ავტომატური დათვლა.

პროდუქტის დეტალური გვერდი და შეფასებები:

1. პროდუქტის სრული მახასიათებლების (ბრენდი, კატეგორია, ფასი (მათ შორის ფასდაკლებული, მარაგში არსებული რაოდენობა, საშუალო რეიტინგი) ნახვა.
2. მოდალური ფანჯრის (Modal) მეშვეობით პროდუქტზე ქულის (1-5) და წერილობითი შეფასების (Review) დატოვება.
3. მოდალური ფანჯრის (modal) მეშვეობით პროდუქტის დეტალური ინფორმაციის გამოტანა.

მოქნილი შესყიდვის სისტემა:

1. შეკვეთის გაფორმების ფუნქციონალზე გადასვლა როგორც კატალოგიდან, ასევე კალათიდან.
2. პროდუქტის სრული მახასიათებლების (ბრენდი, რაოდენობა, ღირებულება, მიტანის საფასური) ნახვა.
3. მიწოდების დეტალების ფორმა (სახელი, გვარი, ტელეფონის ნომერი, მისამართი).
4. გადახდა მეთოდები (პირდაპირ ყიდვა, განვადებით ყიდვა)

ჩემი შეკვეთების გვერდი:

1. პროდუქტის სრული მახასიათებლების (ბრენდი, რაოდენობა, ღირებულება, გადახდის ფორმა, მისამართი, მიმღები) ნახვა.

კომპანიის შესახებ ინფორმაცია:

1. მიწოდების პირობების გვერდი
2. კომპანიის მიზნების გვერდი
