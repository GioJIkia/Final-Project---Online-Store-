
ეს არის სრულფასოვანი ელექტრონული კომერციის (E-Commerce) ვებსაიტი, რომელიც შექმნილია Django ფრეიმვორკის გამოყენებით. აპლიკაცია მომხმარებლებს საშუალებას აძლევს დაათვალიერონ პროდუქცია, გამოიყენონ მრავალმხრივი ფილტრები, მართონ საკუთარი კალათა და დატოვონ შეფასებები/რეიტინგები.

ძირითადი ფუნქციონალი:

ადმინ პანელი (Django Admin):
პროდუქტების, კატეგორიებისა და ბრენდების მართვა (დამატება, რედაქტირება, წაშლა).
მომხმარებლების შეკვეთებისა და კალათების მონიტორინგი.
მომხმარებელთა შეფასებებისა და რეიტინგების ადმინისტრირება.

ავტორიზაციის სისტემა: 
მომხმარებლების რეგისტრაცია.
სისტემაში შესვლა (Login) 
გასვლა (Logout).

პროდუქციის კატალოგი და ფილტრაცია:
ძებნა პროდუქტის დასახელების მიხედვით.
ფილტრაცია კატეგორიის, ბრენდის, მაქსიმალური ფასისა და მინიმალური რეიტინგის მიხედვით.
პროდუქციის სორტირება ფასის ზრდადობისა და კლებადობის მიხედვით.

ინტერაქტიული კალათა:
პროდუქტის კალათაში დამატება როგორც კატალოგიდან, ასევე დეტალური გვერდიდან (გვერდის გადატვირთვის/გადამისამართების გარეშე).
რაოდენობის მართვა (მომატება/დაკლება) და ნივთის წაშლა კალათიდან.
კალათაში არსებული ნივთების ჯამური ღირებულებისა და რაოდენობის ავტომატური დათვლა.

პროდუქტის დეტალური გვერდი და შეფასებები:
პროდუქტის სრული მახასიათებლების (ბრენდი, კატეგორია, მარაგში არსებული რაოდენობა, საშუალო რეიტინგი) ნახვა.
მოდალური ფანჯრის (Modal) მეშვეობით პროდუქტზე ქულის (1-5) და წერილობითი შეფასების (Review) დატოვება.
